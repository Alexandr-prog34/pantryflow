# PantryFlow

## Описание проекта

**PantryFlow** — приложение для совместного учёта домашних продуктов, контроля запасов и ведения списка покупок.

Пользователи могут создавать общее домашнее пространство — `Household` — и приглашать в него членов семьи, соседей или других людей, совместно использующих продукты.

Все участники одного Household видят актуальное состояние домашних запасов и могут совместно ими управлять.

## Основная идея

Основная проблема, которую решает PantryFlow, — отсутствие удобного способа понимать, какие продукты уже есть дома, какие заканчиваются, какие скоро испортятся и что необходимо купить.

Например, пользователь может открыть приложение непосредственно в магазине и проверить, есть ли дома молоко, яйца или другие продукты.

Если одним Household пользуется несколько человек, изменения одного участника должны быть доступны остальным.

## Домашние запасы

Внутри Household пользователи могут хранить информацию о продуктах, находящихся дома.

Для продукта могут быть указаны:

- название;
- категория;
- количество;
- место хранения;
- дата покупки;
- срок годности;
- минимальное желаемое количество.

Продукты могут находиться в разных местах хранения:

- холодильник;
- морозильная камера;
- кухонные шкафы;
- кладовая.

Все участники Household могут:

- добавлять продукты;
- изменять количество;
- удалять продукты;
- менять место хранения;
- указывать срок годности;
- просматривать актуальное состояние запасов.

Например, если один пользователь использовал несколько яиц и изменил их количество в приложении, остальные участники Household должны увидеть новое количество.

## Совместный список покупок

Каждый Household имеет общий список покупок.

Все его участники могут одновременно работать с этим списком:

- добавлять необходимые продукты;
- изменять количество;
- удалять позиции;
- отмечать продукт как купленный.

Таким образом член семьи может добавить продукт в список дома, а другой участник увидит его в приложении во время похода в магазин.

В дальнейшем продукт также сможет автоматически попадать в список покупок, если его количество дома становится меньше установленного минимального значения.

Например:

```text
Молоко

Текущее количество: 0
Минимальное количество: 1

→ добавить в список покупок
```

## Добавление продуктов

Продукты можно будет добавлять вручную или при помощи штрихкода.

При сканировании штрихкода сервер сможет обратиться к внешнему API продуктов и получить доступную информацию:

- название;
- производителя;
- категорию;
- изображение;
- состав;
- пищевую ценность.

Это позволит уменьшить количество данных, которые пользователь должен вводить вручную.

## Контроль сроков годности

PantryFlow будет отслеживать сроки годности продуктов.

Система сможет находить продукты, которые скоро испортятся, и уведомлять пользователей.

Например:

```text
Срок годности молока истекает через 2 дня.
```

В дальнейшем эта проверка может выполняться в фоне независимо от пользовательских запросов.

## Рекомендации рецептов

Информация о домашних продуктах может использоваться для поиска подходящих рецептов.

Например, если дома находятся:

```text
Курица
Рис
Помидоры
Лук
```

PantryFlow сможет обратиться к внешнему сервису рецептов и предложить блюда, которые можно приготовить из этих ингредиентов.

При подборе рецептов также можно будет отдавать приоритет продуктам с приближающимся сроком годности.

## Совместная работа

Одной из важных особенностей приложения является возможность одновременной работы нескольких пользователей.

Например:

```text
Пользователь A использовал 2 яйца.
Пользователь B использовал 1 яйцо.
```

Система должна корректно обработать оба изменения и сохранить правильное итоговое количество продукта.

Аналогичная совместная работа предусмотрена для общего списка покупок.

Это позволит в дальнейшем изучить конкурентный доступ к данным, многопоточность и синхронизацию состояния между клиентами.

## Асинхронные операции

Некоторые операции приложения в дальнейшем могут выполняться асинхронно:

- проверка сроков годности;
- отправка уведомлений;
- обращение к внешним API;
- получение информации о продуктах;
- подбор рецептов;
- обработка импорта большого количества продуктов;
- автоматическое обновление списка покупок.

Для реализации подобных задач планируется использовать возможности Kotlin Coroutines.

## Предполагаемые сущности

В проекте могут использоваться следующие основные сущности:

```text
User
Household
HouseholdMember

Storage
Product
ProductBatch

ShoppingList
ShoppingListItem

Recipe
Notification

```

`ProductBatch` позволит хранить несколько партий одного продукта с разными сроками годности.

Например:

```text
Молоко

Партия №1
Количество: 1
Годен до: 12.10.2026

Партия №2
Количество: 2
Годен до: 18.10.2026
```

## Для чего будет использоваться приложение

PantryFlow предназначен для людей, которые совместно ведут домашнее хозяйство и хотят контролировать продукты.

Приложение позволит:

- видеть продукты, которые уже находятся дома;
- контролировать их количество;
- уменьшить количество забытых и испорченных продуктов;
- следить за сроками годности;
- вести общий список покупок;
- совместно редактировать список покупок нескольким участникам;
- проверять наличие продукта, находясь в магазине;
- получать рекомендации блюд на основе имеющихся ингредиентов.

Таким образом PantryFlow объединяет домашний учёт продуктов, контроль сроков годности, совместный список покупок и рекомендации рецептов в одном приложении.

## Технологии

Планируемый стек проекта:

- Kotlin;
- Ktor — серверная часть;
- Kotlin Coroutines — асинхронные операции;
- Compose Multiplatform — клиентское приложение;
- PostgreSQL — хранение данных;
- Gradle Kotlin DSL — система сборки.
